# 📂 FileVault  

**FileVault** is a Solidity-based project that provides **on-chain access control** for encrypted off-chain file storage.  
The contract ensures that only the uploader of a file can manage access permissions while keeping the actual file data off-chain.  

## 🔨 Current Stage:  
- ✅ **Phase 1** – Smart contract development and testing complete  
- 🚧 **Next** – Backend encryption service (AES + RSA)
